Napat Karaoke Pro (v2.2.0)

Release Notes — v2.2.0 (Universal Auto-Hide & Seamless Playback Experience)
​📱 Native Android APK (Tablet UX & Fullscreen)
​Universal Auto-Hide Button: แก้ไขและปลดล็อกระบบซ่อนปุ่มสลับโหมดให้ครอบคลุมทุกสถานะ ทั้งในโหมดหน้าจอเดี่ยว (index.html) และขณะขยายวิดีโอเต็มจอ (Fullscreen Mode) โดยปุ่มจะจางหายไปโดยอัตโนมัติ ไม่ลอยค้างบดบัง MV หรือเนื้อเพลง
​Touch-to-Wake (8 Seconds): แตะที่หน้าจอจุดใดก็ได้ขณะเพลงกำลังเล่นหรือขณะรับชมแบบเต็มจอ เพื่อปลุกปุ่มสลับโหมดให้แสดงผลชั่วคราวเป็นเวลา 8 วินาที ก่อนจะค่อยๆ จางหายไปใหม่อย่างนุ่มนวล
​Standby Auto-Restore: เมื่อเล่นจบเพลงหรือระบบกลับสู่หน้าสแตนด์บาย ปุ่มสลับโหมดจะกลับมาแสดงผลค้างไว้ตลอดเวลาเพื่อให้สะดวกต่อการกดเปลี่ยนโหมด
​Optimized APK Footprint: คอมไพล์ไฟล์ APK ในขนาดกะทัดรัดเพียง 10.6MB ประหยัดพื้นที่จัดเก็บและโหลดเข้าใช้งานได้รวดเร็ว
​🎵 Core Playback Engine & YouTube Integration
​Full Song Playback (No Early Cutoff): ยกเลิกเงื่อนไขการตัดจบเพลงล่วงหน้า 10 วินาที ปรับให้วิดีโอเล่นต่อเนื่องจนจบสมบูรณ์ 100% ตามเนื้อเพลงจริงก่อนเริ่มระบบคำนวณคะแนน
​Seamless Transition: จัดการหยุดวิดีโอและปิด End Screen Cards ของ YouTube ทันทีที่เพลงจบ เพื่อความสะอาดตาและความต่อเนื่องในการเล่นคิวถัดไป
​🏆 Karaoke Score Pacing
​Optimized Score Duration (6 Seconds): ปรับจังหวะเวลาแสดงผลหน้าต่างคะแนนเพลงหลังร้องจบให้อยู่ที่ 6 วินาที (จากเดิม 3.5 วินาที / 10 วินาที) มอบความกระชับกำลังดี มีเวลาฉลองคะแนนร่วมกันโดยไม่ทำให้คิวเพลงถัดไปรอนานเกินไป
​☁️ Architecture & OTA Updates
​Instant Cloud Deployment: ระบบแยก Logic การแสดงผลบนเว็บออกจากตัว Native APK ทำให้การปรับแต่งระบบเล่นเพลงและคะแนนสามารถอัปเดตผ่าน GitHub / Cloudflare Pages ได้ทันทีแบบ Real-time โดยไม่ต้องติดตั้ง APK ใหม่
